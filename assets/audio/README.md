# 游戏音频素材

本目录中的音频均选自 OpenGameArt，并在下载页面标注为 CC0，可免费用于游戏项目。

## 背景音乐

- `bgm/map-forest.mp3`：太玄宗、青云山麓与幽月森林。
  [Forest Ambience](https://opengameart.org/content/forest-ambience)，TinyWorlds，CC0。
- `bgm/map-dark-ambient.ogg`：修仙大地图的环境曲。
  [Cathedral in the forest](https://opengameart.org/content/cathedral-in-the-forest-ambient-loop)，congusbongus，CC0。
- `bgm/map-underwater.ogg`：东海龙宫与深海秘境。
  [GameOver or Underwater](https://opengameart.org/content/gameover-or-underwater)，gchoc，CC0。
- `bgm/map-dark-temple.ogg`：赤炎秘境、战场、遗迹、雷域、天魔宗等高危区域。
  [Evil temple Ambiance loop](https://opengameart.org/content/evil-temple-ambiance-loop)，Brandon Morris，CC0。
- `bgm/battle.ogg`：普通战斗。
  [Heartfelt Battle](https://opengameart.org/content/heartfelt-battle-loopable-fantasy-stringspianohorn)，request，CC0。
- `bgm/boss-battle.mp3`：Boss 战。
  [JRPG Epic Rock Battle Theme #1](https://opengameart.org/content/jrpg-epic-rock-battle-theme-1)，HydroGene，CC0。

## 音效

- `sfx/move.ogg`：路点移动。
  [Footsteps](https://opengameart.org/content/footsteps-0)，GboxMikeFozzy，CC0。
- `sfx/attack.ogg`、`sfx/hit.mp3`：普通攻击的剑击与命中受击。
  [20 Sword Sound Effects](https://opengameart.org/content/20-sword-sound-effects-attacks-and-clashes)，StarNinjas，CC0；[Hurt Sound Effects](https://opengameart.org/content/hurt-sound-effects)，EZduzziteh，CC0。
- `sfx/escape.ogg`：逃跑动作。
  [Jump and Run and Stand](https://opengameart.org/content/jump-and-run-and-stand)，mieki256，CC0。
- `sfx/victory.mp3`：战斗胜利结算。
  [Victory](https://opengameart.org/content/victory-6)，Musheran，CC0。
- `sfx/skill-fire.ogg`、`skill-arcane.ogg`、`skill-water.ogg`：火系、通用、水/冰系技能。
  [Magic Spell SFX](https://opengameart.org/content/magic-spell-sfx)，JaggedStone，CC0。
- `sfx/skill-heal.ogg`、`skill-thunder.ogg`：治疗/护盾与雷系技能。
  [Spell sounds](https://opengameart.org/content/spell-sounds)，Augmentality，CC0。
